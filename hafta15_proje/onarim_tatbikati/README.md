# "Arkadaşının sistemini onar" tatbikatı

Dört küçük sistem, her biri kasıtlı olarak bozuk. Görev: çalıştır, hatayı bul, düzelt ve `onarim_raporu.md`
dosyasına (sistem başına 3–5 satır) belirti → kök neden → düzeltme → önleme yaz. Süre: 40 dakika.
Çözümler `cozumler.md` dosyasındadır (eğitmen; öğrencilere dağıtmayın).

| Sistem | Alan | İpucu |
|---|---|---|
| `sistem1` | Python / veri | Sayılar neden 0 çıkıyor? |
| `sistem2` | Docker Compose | Servis ayağa kalkmıyor |
| `sistem3` | Kabuk betiği | Boş dosya yazıyor |
| `sistem4` | Model servisi | 200 dönüyor ama tahminler saçma |
